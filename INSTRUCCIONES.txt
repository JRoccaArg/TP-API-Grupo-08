ZENOIR - CÓMO LEVANTAR EL PROYECTO

Hace falta Java 17 o más, Node 20.19 o más y SQL Server.


1) BASE DE DATOS

   En SQL Server Management Studio, crear una base vacía:
      CREATE DATABASE Zenoir_Prod;

   Las tablas las crea el back solo la primera vez que arranca.

   Crear el archivo zenoirprod/config/application.properties con la clave de SQL Server:
      spring.datasource.password=la_clave_de_sa

   Por defecto se conecta a localhost:1433, a la base Zenoir_Prod y con el usuario sa.
   Si la base o el usuario son otros, agregar en el mismo archivo:
      DB_NAME=nombre_de_la_base
      spring.datasource.username=tu_usuario


2) BACK (carpeta zenoirprod)

   En VS Code: abrir la carpeta zenoirprod y ejecutar ZenoirprodApplication.
   O en una terminal, dentro de zenoirprod:
      .\mvnw.cmd spring-boot:run        (en Mac o Linux: ./mvnw spring-boot:run)

   Queda en http://localhost:8080


3) DATOS DE EJEMPLO (opcional)

   Para tener el catálogo con eventos, lugares, entradas y fotos: con el back levantado al menos
   una vez, abrir zenoirprod/database/seed/catalogo.sql en SSMS, elegir la base Zenoir_Prod y
   ejecutarlo con F5. Los pasos completos están en zenoirprod/database/seed/README.md.


4) FRONT (carpeta frontend)

   En otra terminal, dentro de frontend:
      npm install
      npm run dev

   Abrir http://localhost:5173


USUARIOS

   Cualquiera se registra desde "Ingresar" > "Creá una" y queda como comprador.
   Para tener un administrador, registrar la cuenta y correr en la base:
      UPDATE usuarios SET rol = 'ADMIN' WHERE email = 'tu_email';

   El pago es de prueba: en la pantalla de pago está el botón "Usar tarjeta de prueba".
