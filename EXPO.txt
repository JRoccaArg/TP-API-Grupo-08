ZENOIR - VERSIÓN PARA LA EXPO

Esta versión trae una base de SQL Server con todo cargado: cuentas, eventos con flyers y fotos,
lugares, entradas vendidas, QR usados y un evento cancelado. Así se puede mostrar todo sin cargar nada antes.
Hace falta Java 17 o más, Node 20.19 o más y SQL Server.


PREPARAR LA BASE (una sola vez)

1. En SQL Server Management Studio, crear una base vacía:
      CREATE DATABASE Zenoir_Expo;

   Si te conectás con un usuario que no es sa, dale permiso en esa base:
      USE Zenoir_Expo;
      CREATE USER tu_usuario FOR LOGIN tu_usuario;
      ALTER ROLE db_owner ADD MEMBER tu_usuario;

2. Crear el archivo zenoirprod/config/application.properties con los datos de conexión:
      DB_NAME=Zenoir_Expo
      spring.datasource.username=sa
      spring.datasource.password=la_clave
      zenoir.mail.activo=false

3. Levantar el back (ver abajo) para que cree las tablas. Esperar a que diga "Started ZenoirprodApplication".

4. En SSMS, abrir zenoirprod/database/seed/expo.sql, elegir la base Zenoir_Expo arriba a la izquierda
   y ejecutarlo con F5. Tarda unos segundos y tiene que decir "Seed de la expo cargado correctamente."
   No hace falta reiniciar el back.


LEVANTARLO

   Back: en VS Code, abrir la carpeta zenoirprod y ejecutar ZenoirprodApplication.
         O en una terminal dentro de zenoirprod:  .\mvnw.cmd spring-boot:run
         Queda en http://localhost:8080

   Front: en otra terminal, dentro de frontend:
            npm install
            npm run dev
          Abrir http://localhost:5173
