ZENOIR - VERSIÓN PARA LA EXPO

Esta versión arranca con todo cargado: cuentas, eventos con flyers y fotos, lugares, entradas vendidas,
QR usados y un evento cancelado. No hace falta instalar ninguna base ni configurar nada.
Hace falta Java 17 o más y Node 20.19 o más.


LEVANTARLO

   Back: en VS Code, abrir la carpeta zenoirprod y ejecutar ZenoirprodApplication.
         O en una terminal dentro de zenoirprod:  .\mvnw.cmd spring-boot:run
         Queda en http://localhost:8080. Tarda unos segundos más que lo normal porque carga las fotos.

   Front: en otra terminal, dentro de frontend:
            npm install
            npm run dev
          Abrir http://localhost:5173

   Los datos viven en memoria: cada vez que se reinicia el back, todo vuelve a quedar como al principio.
   Sirve para ensayar la expo las veces que haga falta.

CON SQL SERVER (opcional, para que los datos queden guardados)

   1. Crear una base vacía: CREATE DATABASE Zenoir_Expo;
   2. Crear zenoirprod/config/application.properties con:
         DB_NAME=Zenoir_Expo
         spring.datasource.username=sa
         spring.datasource.password=la_clave
         zenoir.mail.activo=false
   3. Levantar el back para que cree las tablas.
   4. En SSMS, abrir zenoirprod/database/seed/expo.sql, elegir la base Zenoir_Expo y ejecutarlo con F5.
      Tiene que decir "Seed de la expo cargado correctamente."

   Con ese archivo el back usa SQL Server; sin él, la base en memoria con todo cargado.
